# LifeLink target UI reference

This folder contains the visual reference supplied for the redesign.

The redesign keeps the existing API/backend flows and focuses on the mobile presentation layer:
- cinematic dark emergency-tech home experience
- premium red/pink SOS interactions
- polished auth surfaces
- floating dark navigation
- glass-style cards and layered gradients
- richer visual hierarchy for health, blood bank, map, AI and agency areas

The reference image is a design target, not a runtime screen.

## Environment

The distributable archive intentionally does not include `.env` or `.git` credentials/secrets. Copy your existing local environment configuration into the project before running it if your setup requires one.
